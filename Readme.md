# COEP Spaces

A venue booking platform for the COEP campus, built by our team of four.<br>
- Ayush Pareek 
- Harsh Mishra
- Nayan Suryawanshi
- Vishal Bhat

Users can browse campus venues, request a booking, and track its approval
without coordinating everything through messages.

### live link
https://coep-spaces-self.vercel.app

backend is hosted on render and frontend on vercel

## tech stack
React, Express, MongoDB 

used jwt for authentication, bcryptjs for password hashing

## to run locally
 
clone the repo<br>
install npm in both client and server folder<br>
create .env in server folder, add JWT secret and mongodbURI
